# ROI Studio — Final Polished

A professional Streamlit ROI image editor. Filters are applied only inside selected ROI masks.

## Features
- Rectangle ROI
- Circle / ellipse ROI
- Freehand ROI
- Multiple regions
- Different filter per region
- ROI-only processing (no accidental full-image filter)
- Before / After view
- ROI manager
- Full-resolution PNG export
- Professional generated ROI Studio logo in the header

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

For Streamlit Community Cloud, upload `app.py`, `requirements.txt`, and the `assets/` folder.
